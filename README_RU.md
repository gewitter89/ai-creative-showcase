# Партия 01 — передача Antigravity

- catalog.json — 9 черновых карточек в точной схеме существующего каталога. Существующие три ID сохранены; описания и цены предложены для новой партии.
- generation_manifest.json — пути будущих превью, промпты, комплектация и статус. Не является рабочим каталогом.
- prompts.md — промпты для ручной генерации в чате, по одному изображению на вызов.

Сейчас image пустой, badge = «В разработке», telegram_contact = заглушка из существующего репозитория. Публичный сайт имеет кнопку «Заказать» даже для пустых карточек, поэтому этот файл не следует автоматически размещать в main. Сначала отключить заказы для незавершённых товаров, назначить реальный Telegram-контакт, сгенерировать и проверить файлы. Для продажи использовать фактические форматы и размеры, не только запланированные. Оригиналы платных цифровых файлов и персональные данные покупателей не размещать в публичном репозитории. Превью без изображений не считать готовым товаром. Для категории 3d сейчас предлагаются только графические референсы, не STL и не готовые к печати модели.

Цены — предложенные тестовые цены в гривнах, без обещания спроса или продаж. Бюджет генерации и размещения 0 грн дополнительных расходов. Не использовать платные API.
