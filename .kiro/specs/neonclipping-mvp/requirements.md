# NeonClipping MVP — Clean-Room Audio-First 9:16 Clipper (Spec)

Источник идеи: Opportunity Radar (`iamajmeena/neonclipping`, https://github.com/iamajmeena/neonclipping).
Юридический статус: оригинал распространяется под лицензией **GNU AGPL-3.0**. В код проекта не заимствуется ни одной строки из `iamajmeena/neonclipping` — реализуется полностью независимая clean-room архитектура на базе идей продукта.
Бюджет: 0 грн доп. расходов (CPU-VPS, Python stdlib + `ffmpeg`/`yt-dlp`, опциональный локальный Ollama на `127.0.0.1` без платных API).

## Требования

1. **Audio-first пайплайн (Fast Mode):**
   - Для URL сначала загружать только аудиопоток и субтитры (`json3` / `vtt` / `srt`), не скачивая целиком длинное видео.
   - Парсить YouTube `json3` пословные субтитры (и `vtt`/`srt` через базовый парсер) с сохранением таймингов слов.
   - Скачивать видеосегменты только для выбранных тайм-окон (`--download-sections`) с безопасным fallback на полный файл при отсутствии поддержки диапазонов.
   - Блокировать небезопасные URL (SSRF-защита: только публичный `http`/`https`, запрет `localhost`, loopback, link-local, private IP).

2. **Многосигнальный локальный скоринг моментов (без numpy/scipy):**
   - Скачок громкости (`loudness_jump`) относительно скользящего локального окна (baseline).
   - Энергия повышенного голоса в полосе **2–4 кГц** (чистый Python Goertzel-анализ по 16 кГц PCM WAV).
   - Контраст «тишина/затишье → всплеск» (`contrast`).
   - Мультиязычные триггеры интереса в тексте (`keyword_hook`: RU/UK/EN маркеры, `?`, `!`).
   - Привязка границ клипа к границам предложений/сегментов речи (`snap_window_to_sentences`) в пределах `[min_duration, max_duration]`.

3. **Локальный LLM-судья и заголовки (0 грн):**
   - Опциональный вызов локального Ollama (`127.0.0.1:11434`, только localhost) для оценки момента, генерации заголовка и opening hook.
   - При отсутствии Ollama или ошибке — детерминированный эвристический генератор заголовка и крючка из текста сегмента.

4. **Рендер 9:16 и стили субтитров:**
   - 5 стилей ASS-субтитров (`neon`, `impact`, `clean`, `hormozi`, `bold_box`) с пословным караоке (`\kf`).
   - Опциональный верхний заголовок-крючок (`opening_heading`) на первые секунды ролика с тёмной подложкой.
   - Компоновки 9:16: `blur_pad`, `center_crop`, `split_cam`.
   - Экспорт `.mp4` (`1080x1920`, `h264`, `yuv420p`, `+faststart`), `.srt`, `.vtt` и `.json` метаданных.

5. **Локальное обучение на оценках (`feedback.jsonl`):**
   - Сохранение оценок 1–5 звёзд в `feedback.jsonl` с историей и дедупликацией по `clip_id` при обучении.
   - Адаптация весов скоринга после накопления не менее 8 разных оценённых моментов с разбросом оценок.

6. **Локальный Web UI + HTTP API:**
   - Сервер на Python stdlib (`127.0.0.1:8770`) с `clipper.html`, API `/api/health`, `/api/clips`, `/api/clip`, `/api/feedback` и безопасной раздачей `/clips/<file>` с защитой от path traversal и поддержкой HTTP `Range`.
