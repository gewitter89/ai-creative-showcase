# NAUM AI Creative Studio — партия 02 (День святого Валентина / весна / универсальные оверлеи)

Девять концепций товаров для следующего сезона. Текущий `catalog.json` (новогодняя партия 01) не изменён. Цены — предложенные стартовые цены, не подтверждённые рынком. Файлы ещё не произведены; генерация выполняется вручную по бюджетному правилу 0 грн без платных API.

## Общий стандарт

Промпты написаны на английском. Генерировать один исходник за вызов; для наборов повторять промпт с указанными вариантами (`[VARIANT]` или `[VIEW]`). Не обещать 4K, PSD, STL/3MF или готовый alpha-канал без фактического файла и ручной проверки. Сохранять оригиналы отдельно от публичных превью. Публичные превью — WebP/JPG, желательно 1200 px по длинной стороне, с сохранением пропорций. Доставляемые платные ZIP-архивы не хранить в публичном репозитории. Все тексты открыток добавить вручную и вычитать.
